# Happy vs Sad Face Classification

## Overview

This project uses a machine learning model to classify facial images as **Happy** or **Sad**.

## Features

* Image preprocessing
* Binary image classification
* Prediction on new face images

## Dataset

The dataset contains images labeled into two classes:

* Happy 🙂
* Sad 🙁

## Usage

Train the model:

```bash
python train.py
```

Predict an image:

```bash
python predict.py --image sample.jpg
```

## Output

```text
Prediction: Happy
Confidence: 96.5%
```

## Technologies

* Python
* TensorFlow/Keras
* NumPy
* OpenCV
